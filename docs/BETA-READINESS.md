# Beta usability and model correctness update

The public `/testing` page gives testers five tasks: compare a trade, inspect a pick, test their own account, inspect Research if granted access, and report useful/confusing behavior directly to Logan. It does not display the access code or grader credentials and does not submit/store a feedback report. Payments remain unchanged.

Mobile navigation now has an accessible Menu/Close control, visible expanded state, keyboard Escape dismissal and 44px targets. Checks at a 390px iframe viewport (375px layout width with the browser scrollbar) found no horizontal overflow on the trade, Daily Picks and tester pages. This is a responsive layout check, not a physical iOS/Android certification. Real-device testing remains useful for keyboards, datalist suggestions and screen readers.

Free page content renders before the account lookup finishes. Account identity still comes from the verified server session, and protected APIs still require Pro. The late account response does not reset trades or searches on the free pages. Research and Account update once identity is known. Sign-in return links allow only Research, Account or Pricing; arbitrary redirects are rejected. Signed-in free users see Manage access instead of a redundant Sign in prompt.

The NBA chronological replay now chooses team identity only from earlier rows and skips uncertain transition/return-team targets. It does not use a held-out target's team to choose historical training rows. The NBA minutes shift test now requires at least two measured current and five measured prior appearances, rather than counting games with missing minutes as supporting measurements. Coverage is disclosed in the input audit. The NFL role guard detects positive current workload after a verified zero prior workload, while negative, boolean and missing opportunity counters are invalid rather than measured zero. The existing outcome weighting and gate counts are unchanged. New Daily Picks reports identify `season-team-guard-v4-temporal-coverage`; frozen forecasts are never rewritten. These are correctness fixes, not evidence of higher prospective accuracy. Shadow comparisons and later game results remain necessary for accuracy claims.
